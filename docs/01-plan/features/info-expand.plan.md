# Plan — 정보 탭 확장 (연찬회 안내문 실무정보 반영)

> Feature: `info-expand` · 2026-06-20 작성 · 기반: 「2026 도시과학대학 국제학술 발전포럼 안내문」

## Executive Summary

| 관점 | 내용 |
|------|------|
| Problem | 안내문의 실무 정보(비상연락처·준비물·유의사항·수하물·항공 집결)가 앱에 없어, 참가자가 종이 안내문을 따로 봐야 함. 게다가 출국 항공편 번호가 앱(KE723)과 안내문(KE5868)이 불일치. |

| Core Value | "종이 안내문 없이도 출발 전~현지 내내 폰 하나로 끝나는" 실무 신뢰성. |

## 1. 결정 사항 (확정)

- ✅ **정보 탭 확장** (새 탭 신설 안 함 → 라우터/탭바 무변경)
- ✅ **조별 명단·객실 배정 제외** (분량·개인정보)
- ✅ 모든 데이터는 `js/data.js` `TRIP` 객체에 추가, 렌더는 `js/render.js` `renderInfo()` 확장

## 2. 데이터 정정 (선행 — 버그 수정)

## 3. 추가 콘텐츠 (안내문에서 선별한 7항목)

`TRIP.info` 객체(신규)로 구조화하여 `renderInfo()`가 섹션으로 출력.

1. **비상 연락처** — (주)마스터스투어 장현철 사장 010-3386-3950. `tel:` 링크.
2. **항공·집결** — 출국 KE5868 09:35(07:00 인천 T2 3층 B·C·D 수속, 09:00 게이트 집결) / 귀국 LJ236 18:10 도착.
3. **준비물 체크리스트** — 여권+사본·여권사진2매 / Visit Japan Web QR(72h 전 등록) / 멀티어댑터(110V '돼지코') / 우산(필수) / 비즈니스 캐주얼 / 엔화 현금(소액권) / 상비약.
4. **호텔 (Visit Japan Web 입력용)** — 몬트레 교토 주소(영·일문)·전화. ※시스템 입력은 영/일문만.
5. **현지 유의사항** — 좌측통행 / 전용버스 음식물 금지(생수만) / 호텔 욕실 샤워커튼 안쪽 / 여행자보험 2억(사고 시 진단서·경찰신고서 확보).
6. **수하물 규정** (접이식) — 위탁 1인 1개·20kg, 위탁불가(보조배터리·라이터·전자담배), 액체류 100ml·총1L 지퍼백.
7. **출입국** — Visit Japan Web 72시간 전 등록 + QR 캡처, 여권 훼손 주의.

### 제외 (지엽적/부담)
- 면세점 액체 봉인봉투 세부 규정, 마일리지 적립 안내, 53명 조별 명단, 객실 배정표.
